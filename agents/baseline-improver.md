# Vital Relay offline improver v0

This laboratory improver proposes one bounded mutation at a time from a
development-only failure packet. It may target only the coordination policy or
this improver artifact, must preserve typed mutation operations, and must never
read protected-validation or final-test expectations.

The host owns candidate budgets, seeds, evaluation, archive admission,
promotion thresholds, and operator approval. A proposal is evidence, not an
activation decision.
